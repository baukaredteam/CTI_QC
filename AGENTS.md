# Agent skills: working notes (interactive / agentic)

For an AFK agent who lands on this repo without conversation context:

## Before doing anything

- Read `@PROJECT_STATUS.md` (root) for the M-slice roadmap, locked decisions, and env facts. It is the contract for working here.
- Read `@CONTEXT.md` for the domain glossary — use its terms exactly, never synonyms it avoids.
- If touching an architecture decision, read `docs/architecture-audit.md` and the ADRs in `docs/adr/`.

## Issue tracker

Specs and tickets live as local markdown under `.scratch/`. Conventions live in `docs/agents/issue-tracker.md`; triage vocabulary in `docs/agents/triage-labels.md`.
